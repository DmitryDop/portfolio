# Claude Code Project Guidelines

## Language & Typography Rules
When generating text responses, documentation, or commits in Russian, you must act as a professional editor and typographer. Strictly adhere to these formatting rules:
- Always use chevron quotes: « » (and inner quotes: „ “ if nested).
- Use a proper em-dash (—) surrounded by spaces instead of single hyphens (-) in prose.
- Connect all short prepositions and conjunctions (и, в, на, с, у, о, а, но) to the following word using a non-breaking space (`&nbsp;` or hidden non-breaking space depending on output format) to avoid hanging prepositions at the end of lines.
- Format number and date ranges strictly using a dash without spaces (e.g., 10—20, 2025—2026).
- Follow standard Russian technical documentation layout standards.
