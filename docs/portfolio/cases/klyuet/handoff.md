## Сертификат

Ссылка «Посмотреть сертификат» использует предоставленный `_x/diploma26229759-2.png` (1920×1080). Для production его точная копия сохранена в `assets/img/case-klyuet/certificate-full.png`; исходный файл не изменён. Без JavaScript ссылка открывает оригинал напрямую.

С JavaScript открывается нативный модальный `dialog` с затемнением фона, кнопкой закрытия справа вверху, закрытием по Escape и нажатию на фон. Клик по изображению переключает вписывание и исходный размер с прокруткой. Фокус возвращается на ссылку.
